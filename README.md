## Запуск

1. **Клонировать репозиторий:**
```bash
git clone https://github.com/EkaEkaEkaRy/Wish_list.git
```

2. **Установить зависимости:**
```bash
flutter pub get
```

3. **Запуск:**
```bash
cd wish_list
flutter run
```

## Сборка

```bash
# APK
flutter build apk --release

# IOS
flutter build ios --release
```
